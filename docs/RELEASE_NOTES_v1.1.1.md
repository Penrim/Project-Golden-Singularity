# Golden Sun Collection 1.1.1

**Fix: building works again.** In 1.0.0 and 1.1.0 the builder stopped with the message
"cart/prebuilt/... does not match cart/runtime.c" for everyone who downloaded the project and has no ARM compiler
installed — that is, for every player. Sorry about that! This version fixes it.

- Nothing else changed: the finished cartridges are identical to 1.1.0 (same checksums), and your save files keep
  working.
- Supported languages: English, German, French, Italian, Spanish.

**This release contains no game files.** Download the source code below, copy your two ROM files (same language)
into the `roms` folder and double-click `Build (Windows).bat`, `Build (macOS).command` or `build-linux.sh`.
Details: README.md and BUILDING.md.
