# Project Golden Singularity 1.2.3

**A painted background for the "Chapter 2" card.**

- The "Chapter 2" card between the two games now shows a painted valley with a distant lighthouse and a ship, in
  the soft style of the two games' title screens, instead of a dark screen with a plain sun. The texts are the
  same, now with outlines so they stay readable. All five languages.
- The background was drawn new (generated locally with the MOSS-Image model; nothing taken from the games); the
  prompt and settings are in art/README.md.

Nothing else changed: apart from the card picture the cartridge is byte for byte the same as 1.2.2. The switch to
Chapter 2 was tested again in all five languages. Your save files keep working.

**This release contains no game files.** Download the source code below, copy your two ROM files (same language)
into the `roms` folder and double-click `Build (Windows).bat`, `Build (macOS).command` or `build-linux.sh`.
Details: README.md and BUILDING.md.
